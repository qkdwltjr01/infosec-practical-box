# 정보보안기사 실기 연습장

알기사 실기 이론편을 **구조 → 읽기 → 인출** 순서로 공부하는 웹앱. 파일 하나(`index.html`)로 돌아간다.

- 웹: https://qkdwltjr01.github.io/infosec-practical-box/
- 로컬: `index.html` 더블클릭 (인터넷 없이도 돌아간다)

## 하는 것

| 탭 | 내용 |
|---|---|
| 오늘 | 그날 블록(B1 ~ B50), 이론편 쪽수, 블록별 시간, 저녁 단답 쪽수 |
| 블록 공부 | ① 구조: 단계 버튼(`1.` `(1)` `1)` `(가)` `①` 💡보안멘토)이나 Tab/Shift+Tab으로 단계만 고르고 제목을 적으면 번호가 자동으로 붙는 지도(트리) 편집기. 줄을 넣고 빼도 키워드는 그 줄을 따라간다 · ② 읽기: 칸마다 키워드 메모 + 모르는 말 바로 묻기 · ③ 인출: 키워드를 가린 지도를 다시 채우고 채점 · ④ 휴식. 타이머는 블록 쪽수에 맞춰진다 |
| 아침 복습 | 전날 블록 지도 다시 채우기, PART 전체 총정리 |
| 저녁 퀴즈 | 칸과 어휘 카드를 섞어서 떠올리기, 자주 틀린 칸 먼저 |
| 어휘장 | 읽다가 물어본 말과 내 말로 정리한 것 |
| 헷갈리는 쌍 | 이름이 비슷해서 섞이는 개념 (예: OSPF / OCSP) |
| 기록·백업 | 클라우드 동기화, 백업 파일 내보내기·불러오기, 블록별 점수, 자주 틀린 칸 |

지도와 키워드는 미리 들어 있지 않다. 교재를 보고 직접 넣는다. 채점은 내가 적은 키워드와의 **글자 비교**라서 내용이 맞는지는 판단하지 않는다.

**모르는 말 바로 묻기.** 이 페이지는 Claude에 연결되지 않는다. 모르는 말과 질문 방식(쉬운 말로 · 비유·예시로 · 왜 필요한지 · 비슷한 것과 차이)을 고르면 질문 문장을 만들어 복사해 주고, 그걸 Claude에 붙여 넣는다. 설명을 읽은 뒤 "내 말로 정리"를 어휘장에 저장하면 인출·아침 복습·저녁 퀴즈에서 다시 나온다.

## 동기화

기록은 기본적으로 그 브라우저의 localStorage에만 있다. **기록·백업 → 클라우드 동기화**에 토큰을 넣으면 기록이 내 GitHub 계정의 **비공개 Gist** 한 개(`infosec-practical-state.json`)에 올라가고, 같은 토큰을 넣은 기기(PC 파일, 웹 주소, 폰)가 같은 기록을 쓴다.

토큰: GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → 권한은 **gist** 하나만. 토익 단어 상자에 쓰던 토큰을 그대로 써도 된다. 토큰은 브라우저에만 남고 Gist에는 올라가지 않는다.

**병합 규칙.** 통째로 덮어쓰지 않고 항목마다 합친다. 순서를 바꿔도, 여러 번 돌려도 결과가 같다.

| 대상 | 규칙 |
|---|---|
| 블록 지도·키워드 | 블록마다 마지막으로 고친 쪽 |
| 인출 기록 | 합집합 |
| 칸별 맞음/틀림 횟수 | 큰 쪽 |
| 어휘장 | 항목마다 마지막으로 고친 쪽, 알았음/몰랐음은 큰 쪽. 지운 것은 되살리지 않는다 |
| 헷갈리는 쌍 | 합집합. 지운 것은 되살리지 않는다 |

`file://`로 열던 페이지와 웹 주소는 브라우저가 서로 다른 저장소로 취급한다. 옮길 때는 **쓰던 쪽에서 먼저 연결 → 새 쪽에서 같은 토큰으로 연결** 순서로 한다.
